# stsp001_capstone_insurance_helper

Step 1 Create a Virtual Environment:

python -m venv venv  
(for mac: python3 -m venv venv)

To activate: .\venv\Scripts\activate
(for mac: source venv/bin/activate)

To deactivate (also for mac): deactivate (or auto deactivate once closed)

Step 2 Download requirements.txt

pip install -r requirements.txt 

//Running the main in the venv file: python main.py
